# {{name}}

A one-page site built with Vite, React, TypeScript and Tailwind.

## Run it

    npm install
    npm start

Then open the address it prints, usually http://localhost:5173.
(`npm start` and `npm run dev` do the same thing.)

## Other commands

- `npm run build` — type-check and build for production into `dist/`
- `npm run preview` — serve the production build
- `npm run lint` — lint the source

## Where things are

- `src/content/site.ts` — all the words and details on the page, in one file
- `src/components/sections/` — one file per section of the page
- `src/components/layout/` — the header and footer
- `src/components/ui/` — small pieces reused across sections
- `src/index.css` — the colors and fonts, as design tokens
