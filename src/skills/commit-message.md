---
name: commit-message
description: How to write a commit message for this repository
---

Write the subject as `type: description` using one of feat, fix, refactor,
docs, test, chore, perf or ci. Keep it under 72 characters, lower case after
the colon, no trailing period.

Explain **why** in the body, not what the diff already shows. If the change
fixes a bug, describe the broken behaviour first, then the fix.

Never add `Co-Authored-By` or other attribution trailers: this repository has
them disabled globally.
